# 신학 검수 요청서 — Season 1 파일럿 (DAY 01–07)

> **현재 상태: 모든 원고 `theologyReviewPending` (신학 검수 대기)**
> 이 원고는 AI의 도움으로 작성되었고 자동 검증(구조·분량·참조·중복·저작권 n-gram)을 통과했습니다.
> **사람 신학 검수자의 검토를 아직 받지 않았습니다.** 자동 검증 통과는 신학적 승인이 아닙니다.
> 앱 화면(읽기 화면 하단, 설정 > 콘텐츠 안내)에도 이 상태가 그대로 표시됩니다.

## 1. 검수 절차 제안

1. 검수자는 아래 "확인 요청 항목"을 우선 검토하고, 각 JSON 원고(`assets/content/season1/dayNN.json`)를 20분·심화 모드 기준으로 통독합니다.
2. 수정이 필요하면 원고 JSON을 고친 뒤 `dart run tool/validate_content.dart`로 재검증합니다.
3. 승인된 챕터는 `reviewStatus`를 `approved`로 바꾸고 `contentVersion`을 올립니다.
   현재 검증기는 AI 초안이 자동으로 `approved`가 되는 것을 막기 위해 `approved`를 오류로 처리합니다.
   사람 검수 기록(검수자, 날짜)을 남길 필드를 추가한 뒤 이 규칙을 완화하는 것을 권장합니다(다음 버전 작업).

## 2. 적용한 신학 원칙 (작성 가이드 `docs/CONTENT_GUIDE.md` 2장)

- 정통 기독교 핵심 신앙, 원래 문맥 우선, 무리한 예표 금지.
- 신약의 **명시적 해석**("신약성경은 이 장면을 직접 이렇게 해석합니다"), **전통적 해석**("많은 그리스도인은 ~로 읽어 왔습니다"),
  **해설자의 추론**("본문이 직접 말하는 내용이라기보다…")을 문장 수준에서 구분.
- 본문에 없는 대화·감정을 사실처럼 쓰지 않음. 상상은 "상상해 보면"으로 표시.
- 교단 간 이견(창조의 날, 홍수 범위, 원죄 이해, 세례, 벧전 3:19 등)은 여러 견해를 나란히 소개하고 단정하지 않음.

## 4. 챕터별 확인 요청 항목

작성 과정에서 원고 작성자가 "사람 검수자가 반드시 확인해야 한다"고 표시한 항목입니다.

### DAY 01 — 세상은 왜 창조되었을까?
- 교회사 요약 확인: 아우구스티누스(순간 창조, 6일은 가르침의 순서), 칼뱅(실제 날), 이레네우스(형상과 모양 구분).
- 고대 근동: 에누마 엘리시(마르둑·티아마트, 반역 신의 피로 인간), 아트라하시스, 멤피스 신학(프타의 말 창조 — 말씀 창조가 창세기만의 고유성은 아님을 인정), '신의 형상'의 왕 칭호 용례, 해·달 이름 생략을 해·달 숭배와의 거리두기로 보는 견해("많은 학자"), 테홈–티아마트 연관(논쟁적).
- 초대교회가 몸·물질 경시 가르침(영지주의 암시)에 맞선 근거로 창조의 선함 사용 — 이름 없이 언급.
- 헬라어: 요 20:22와 LXX 창 2:7의 같은 동사(추론 표기).
- 해석: 하나님의 형상–우상 금지(출 20:4) 연결은 추론 표기, 골로새서의 그리스도 "형상의 원형이자 완성"("셈입니다"), 창 1:26 "우리"(삼위 암시 전통 + 위엄 복수 + 천상 회의).
- 히브리어: 1:27 "창조하다" 3회, '거룩' 첫 등장 2:3, 일곱째 날 저녁·아침 후렴 없음, 에제르의 하나님 사용(시 121:1–2), 2:4의 욤이 창조 기간 전체 지칭.
- 창 1:1 독립문/시간절 두 독법, 무로부터의 창조는 요 1:3·히 11:3으로 뒷받침.
- 창조의 '날' 해석: 24시간설·날-시대설·틀 가설·유비적 날·우주 성전 독법을 선택 없이 소개.

### DAY 02 — 인간은 왜 하나님을 떠났을까?
- 원죄 교리 개관(심화): 롬 5:12 '에프 호'와 불가타 'in quo'(아우구스티누스), 개혁파 언약적 대표·행위 언약, 동방정교회 '조상의 죄', 웨슬리안 선행은총, 유대교 선한/악한 성향 — 한 줄 요약. 공정성·누락 확인.
- 창 1–3장 장르와 아담의 역사성 학계 논쟁을 언급하는 한 문장(입장 없음) — 이 독자층에 남길지 결정 필요.
- 호 6:7 "아담처럼" vs 지명 아담 — 행위 언약 근거로 언급.
- 지혜서 2:24: 중간기 유대 문헌, 가톨릭·정교회의 제2경전으로 소개.
- 학자 관찰(완화 표현): 창 1–11의 '저주' 5회(3:14, 3:17, 4:11, 5:29, 9:25) vs 12:2–3의 '복' 5회, 에덴–성막 평행(미트할레크: 레 26:12, 신 23:14, 삼하 7:6, 그룹, 동쪽 입구), 동쪽으로의 이동 모티프, 바벨론 포로 메아리.
- 고대 근동: 우라이우스 코브라와 이집트 혼돈의 뱀, 길가메시의 회춘 식물을 가져간 뱀, 앗수르 성수(聖樹).
- 확인 필요: 3:16의 '다스림'을 죄로 인한 왜곡으로 보는 "많은 해석자"(여러 해석 있음 명시), 추방=자비 독법은 "초대 교회 이후 여러 해석자"로 일반 귀속, 아담의 불신 vs 그리스도의 신뢰 대비는 바울과 창 3을 함께 읽은 독법으로 표기.
- 명시적 신약 해석: 롬 5, 고전 15, 계 12:9·20:2, 고후 11:3. 전통적 독법: "어디 있느냐"=숨은 자를 찾으시는 하나님, 추방=자비, 눅 3–4의 새 아담.
- 창 3:15는 해석하지 않음(DAY 03로 넘김), 가죽옷은 5분 이야기에서 해석 없이 1회 언급.

### DAY 03 — 하나님은 실패한 인간을 포기하셨을까?
- 창 3:15: 문맥상 의미 먼저 → 정경 전체로 읽은 그리스도 해석(이레네우스, '원시복음' 명칭은 후대) → "신약은 3:15를 성취된 예언으로 직접 인용하지 않는다" 명시. 균형 확인 필요.
- '후손' 단수/집단: LXX의 중성 명사 뒤 남성 대명사("일부 학자"), 히에로니무스 라틴역 여성형과 중세 마리아 해석, 현대 가톨릭 공인 라틴역(노바 불가타)이 히브리어에 맞춰 수정했다는 주장 — 확인 필요. 가톨릭 관련 서술은 중립적이나 민감.
- 탈굼(위-요나단, 네오피티)의 '메시아 왕의 날' 연결 및 연대 논쟁 서술 확인.
- 롬 16:20의 '상하게 하다' 동사와 LXX 창 3:15 동사의 차이 확인.
- 기타: 지혜서 2:24 연대(기원전 1세기경), 닛사의 그레고리우스(가죽옷=죽을 몸), 이레네우스–폴리카르포스("전해집니다"), 고대 근동(아펩, 왕관의 코브라, 길가메시 뱀), 조약 저주 목록과 신 28 비교.
- 추론 표기 항목: 아담의 하와 명명=믿음의 응답(통치 시작 독법도 소개), 가죽옷=동산 밖까지 동행하는 돌봄, 제사장 의복 연결(심화 노트), 눅 15:22·갈 3:27과 가죽옷 병치, 히 2:14–15를 머리·발꿈치가 한 죽음에서 맞는 장면으로 읽기, 롬 8:19–22를 저주받은 땅의 메아리로.
- 가죽옷의 제사 예표 해석은 "후대 해석 전통"으로 명시.
- 성장 노트에서 개혁신학의 '은혜 언약' 용어를 명시하고 다른 전통은 다른 용어를 쓴다고 서술 — 공정성 확인.
- 갈 3:16 노트는 창 3:15가 아니라 아브라함 약속 해석임을 명시.

### DAY 04 — 가인은 왜 동생을 죽였을까?
- 창 4:25 '다른 씨'와 3:15의 같은 히브리어 단어 연결 — "많은 그리스도인이 읽어 온" 해석으로 표기. 적절성 확인.
- "고발하는 피 vs 용서하는 피"(히 12:24 + 눅 23:34) — 통상적 해석이나 본문 문자보다 약간 나아감. 심화 노트에 헬라어 직역 "아벨보다 낫게"와 아벨 자신(11:4)/제사와의 비교 견해 소개.
- 마 18:22와 라멕(창 4:24 LXX '일흔일곱') — "일흔일곱 번"/"일흔 번씩 일곱 번" 두 번역 모두 언급. 표현 확인.
- 아벨을 그리스도의 예표로 본 교회 전통 언급, 신약의 연결은 히 12:24로 한정.
- 추론 표기: 가인의 성읍=하나님 없이 안전 추구, 분노가 하나님에게서 동생으로 전이, 형식적 제물, 의인은 미움을 부르는 거울처럼 느껴질 수 있음.
- 히브리어·유대 배경 확인: 4:7 '다스릴지니라'의 명령/의무/가능/예언 독법, '엎드려 있다' 동사와 메소포타미아 문지방 악령 연결(미확인 표기), 4:10 복수형 '피들'의 랍비 해석(미쉬나 산헤드린 4:5), 4:13 '벌/죄' 이중 의미, '원함(테슈카)' 구약 3회(창 3:16, 4:7, 아 7:10), 4:8 가인의 말 공백과 LXX·사마리아 오경의 "들로 나가자".
- 고대 근동: 메소포타미아 예배=신들을 먹이고 돌봄, 법정 이전 혈족 복수 — 완화 표현 사용.

### DAY 05 — 홍수 속에도 은혜가 있었을까?
- 벧전 3:19–21: '옥에 있는 영들' 세 견해(노아를 통한 그리스도의 선포 / 창 6:1–4·에녹1서와 연결된 타락한 영들에 대한 승리 선포 / 죽은 자들에게 내려가심), 세례 세 강조(은혜를 실제로 주심 / 이미 받은 구원의 공적 고백 / 언약의 표), eperōtēma '간구/서약' — 결론 내리지 않음. 공정성 확인.
- 홍수–십자가 연결("같은 물이 심판하고 방주를 들어 올림")은 롬 3:25–26과 함께 신학적 독법으로 표기.
- "순종보다 앞선 은혜"(6:8–9): 본문 순서에서 나온 관찰로, 해석자마다 무게가 다름을 명시.
- 해석 표기: 무지개=걸어 둔 전쟁 활, 홍수=창조의 해체와 재시작, 8:21=하나님의 인내, '기억하시는 하나님' 노아→십자가 강도, 벧전의 '여덟 명'=작은 고난의 교회 위로.
- 히브리어·헬라어 확인: 노아(노아흐)와 은혜(헨)의 자음 역순, 6:6 니함과 5:29 '위로' 어근, 6:11–13 샤하트(부패/멸하다), 테바(방주) 이곳과 출 2만, 8:21 '키'(때문에/~에도 불구하고), 6:18 '언약' 첫 등장.
- 사실 확인: 규빗 약 45cm, 홍수 날짜(7:11, 8:4, 8:14), 길가메시(우트나피쉬팀, 제물에 파리처럼 모인 신들), 아트라하시스 '소음' 동기(학계 이견은 심화 노트).
- 홍수 범위(전 지구/지역) 양쪽 공정 소개, 지질·고고학 주장 없음.
- 성장 노트의 노아 가족–아브라함 약속 연결은 서사 흐름 독법.

### DAY 06 — 사람들은 왜 바벨탑을 세웠을까?
- 행 2와 바벨: 주제적 비교로만 제시. 본문에 "행 2는 창 11을 인용하지 않으며 베드로는 요엘·시 16·110을 인용"이라고 명시. 교부(나지안조스의 그레고리우스 등) 언급은 일반적 표현으로만.
- 빌 2와 바벨: "신학적 묵상"으로 표기. 강조 문장 "하나님이 내려오셔서 이름을 주십니다" — 빌 2에서는 아들이 낮아지고 아버지가 이름을 주심. 이 압축 표현이 적절한지 검토 필요. 빌 2:11의 '글로싸'와 바벨 연결도 묵상으로 표기.
- 갈 3:8: 아브라함 복과 복음의 명시적 연결로 제시(바벨 언급은 없음).
- 흩으심의 은혜적 측면(땅 충만, 9:11과의 연결)은 추론으로 표기. 11:6을 집단적 악의 제어로 읽는 견해는 "많은 해석자" 귀속.
- 히브리어 확인 필요: 바벨/발랄 언어유희(어원 아님), Bab-ili "신의 문"(흔한 풀이), 하바 3회(3·4·7절), 닐베나/나블라 자음 역전, 샴·셈·샤마임 음향, 셈 이름과 '이름' 단어.
- 헬라어: LXX 창 11:7,9 '혼잡' 동사와 행 2:6 동사의 어근 공유(누가 의도 단정 안 함).
- 역사 확인 필요: 에테메난키 뜻, 에누마 엘리시의 벽돌·에사길라, 요세푸스의 니므롯 주도설, 창 10의 70 민족 전통, 메소포타미아 왕들의 벽돌 명문. 지구라트 배경은 절제 서술.
- 논쟁적 해석: 벨렉(10:25) 연결은 가능성, 벧전 5:13 바벨론=로마는 "많은 학자", 사 14는 바벨론 왕 중심 + 사탄 해석은 교회 전통, 11:7 복수형 "우리"는 여러 견해(삼위일체 암시는 전통).
- 창 10과 11은 엄격한 연대기가 아닌 문학적 배열로 제시("많은 해석자").
- 언어 기원: 모든 언어가 바벨에서 왔는지 단정하지 않음.
- "상상해 보면" 표기된 상상 장면 1곳(바빌론 포로기).

### DAY 07 — 하나님은 왜 아브라함 한 사람을 부르셨을까?
- 행 7:2–4와 창 11:26–12:4: 세 조화 방식(부르심이 우르에서 시작 — 창 15:7·느 9:7 / 아브람이 장자가 아님 / 사마리아 오경의 데라 145세)을 견해로 제시. 본문의 연대 계산(아브람이 장자라면 떠날 때 데라 생존) 확인 필요.
- 갈 3:16 단수 '자손': 제라·스페르마는 집합 명사이며 바울도 알았음(3:29), 창 13:15·17:8 연결, "한 메시아 안에 모임"은 많은 해석자의 견해로 제시. 어조와 구절 연결 확인.
- 창 12:3 니브레쿠: 수동(복을 얻다)/재귀(너로 자신을 축복하다) 두 독법, LXX·갈 3:8은 수동.
- 창 12:6 "그때에 가나안 사람이 그 땅에 있었더라": 후대 서술자 관점 / 약속과 현실의 의도적 대비 — 저작·연대 문제와 닿아 이 독자층에 민감할 수 있음.
- 관찰·추론 표기: 일곱 겹 약속, '복' 5회 vs 앞선 저주(3:14, 3:17, 4:11), 축복하는 자(복수)/저주하는 자(단수)와 다른 동사, 렉 레카(12:1, 22:2), 셈('이름')과 셈 족보 언어유희, 탑을 보러 '내려오신' 하나님(11:5), 히 11:10과 바벨(성경 전체 독법), 바벨론 포로 메아리, 하란에서 멈춘 데라와 끝까지 간 아브람.
- 역사(완화 표현): 우르는 남부 메소포타미아 도시로 흔히 보나 북부설도 있음, 우르·하란 달신 숭배(데라 개인 신앙 단정 경계, 근거는 수 24:2뿐), 도시 수호신, 우르–하란 직선 약 1,000km.
- 창 15:6은 갈 3:6이 인용한 출처로 정확히 표기. 12장의 침묵 속 출발과는 "같은 결"로만 연결.
- 편집 중 수정: 아브람이 12장에서 말하지 않는다는 질문을 12:1–9로 한정(12:11–13에서 말함), 22:18 노트 "이삭을 바치려 했던", 우르 지구라트 연대 표현 완화.
